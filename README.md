# Simple Interest Calculator

## Project Name: Simple Interest Calculator

This project provides a simple Bash-based calculator to compute **Simple Interest** based on user-provided inputs.

## Description

Simple Interest is a quick method of calculating the interest charge on a loan or investment. This tool accepts:
- **Principal** – the initial amount of money
- **Rate of Interest** – the annual interest rate (in %)
- **Time Period** – the duration (in years)

And outputs the calculated simple interest.

## Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Usage

```bash
bash simple-interest.sh
```
